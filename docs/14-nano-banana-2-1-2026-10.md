## 1. Model ID

Tên hiển thị trong app là tên thương mại của Google, model ID là chuỗi gửi lên API. Tất cả đều là bản GA.

| Tên hiển thị | Model ID | Vai trò trong app | Hằng số (`constants/aiModels.ts`) |
| :--- | :--- | :--- | :--- |
| Nano Banana 2.1 | `gemini-nano-banana-2.1` | **Mặc định** (`GEMINI_MODEL_FALLBACK`) | `GEMINI_NANO_BANANA_2_1` |
| Nano Banana Pro | `gemini-3-pro-image` | User chọn được | `GEMINI_NANO_BANANA_PRO` |
| Nano Banana 2 | `gemini-3.1-flash-image` | Chỉ khi admin rollback | `GEMINI_NANO_BANANA_2` |

**ID preview cũ** (`gemini-3-pro-image-preview`, `gemini-3.1-flash-image-preview`) vẫn có thể còn trong Firestore, localStorage hoặc request từ tab mở sẵn. `canonicalGeminiModelId` đổi chúng sang ID GA tương ứng. Hàm này được gọi trong `normalizeGeminiModelId`, `resolveModelKey`, `resolveGeminiRequestModel` và bảng giá, nên không ai mất lựa chọn đã lưu.

Đã xác minh bằng API thật (2026-10-08):

- Cả 3 ID đều có trong `models.list` và hỗ trợ `generateContent`.
- 2.1 tạo ảnh 1K mất 12.4–14.5 giây (5 lần). Pro GA mất 16.5 giây (1 lần).
- Script kiểm tra: `npx tsx --env-file=.env.local scripts/verify-nano-banana-2-1.ts [modelId] [runs]`.

## 2. Danh sách model user thấy

`getEnabledModelOptions(enabledProviders, adminGeminiModel)` trả 2 mục Gemini: **model Flash đang hoạt động** (2.1, hoặc Nano Banana 2 khi rollback) và **Pro**.

`resolveModelKey(enabledProviders, preferredKey, adminGeminiModel)` xử lý lựa chọn user đã lưu:

- Đã lưu Nano Banana 2 hoặc 2.1 (preview hay GA) → model Flash đang hoạt động. Không ghi đè localStorage, nên rollback rồi bật lại 2.1 vẫn đúng.
- Đã lưu Pro (preview hay GA) → giữ Pro.
- Chưa lưu gì → mục đầu tiên (2.1).

## 3. Rollback 2.1 → Nano Banana 2 (không cần deploy)

Admin → Cấu hình → Gemini → chọn `Nano Banana 2 (cũ – dùng để rollback)` → Lưu. Các bước kiểm tra nằm trong `docs/06-live-deployment.md` § Rollback.

### Cờ `geminiFlashRollback`

Rollback **chỉ** có hiệu lực khi `settings/global.geminiFlashRollback === true`. Lúc lưu, `useAdminSettings` tự ghi cờ này: `true` khi chọn Nano Banana 2, `false` khi chọn model khác.

`getAdminGeminiModel(settings)` là hàm duy nhất đọc setting admin. Client (`useGlobalSettingsAndApiKey`), màn Merge (`AppAuthenticatedShell`), server (`server/routes/generate.ts`) và trang Admin đều đi qua hàm này.

> **Vì sao cần cờ riêng:** trước khi có 2.1, `settings/global.geminiModel` lưu sẵn `gemini-3.1-flash-image-preview`, vốn là giá trị mặc định cũ. Bản đầu tiên coi "geminiModel = NB2" nghĩa là đang rollback, nên header vẫn hiện Nano Banana 2 cho mọi user. Dữ liệu cũ không có cờ giờ được hiểu là 2.1.

`firestore.rules` → `isSafeGlobalSettings()` có thêm key `geminiFlashRollback`. **Phải deploy rules trước app**, nếu không Admin sẽ không lưu được Settings.

### Phía server

`server/lib/resolveGeminiModel.ts` gọi `resolveGeminiRequestModel(requested, admin)` trong `constants/aiModels.ts`:

- ID hợp lệ (preview đã được đổi sang GA): Flash (2.1 hoặc NB2) → model Flash đang hoạt động; Pro → Pro.
- ID lạ hoặc thiếu → model admin nếu hợp lệ, ngược lại là model Flash đang hoạt động.
- Trước đây server dùng nguyên `body.geminiModel` mà không kiểm tra.

## 4. Kích thước ảnh 512px

API trả `400 Image size 512px is not supported for this model` cho **2.1 và Pro**. Nano Banana 2 vẫn hỗ trợ 512px.

- `getUnsupportedImageSizes(model)` là nguồn dữ liệu chung cho client và server.
- `ImageSizeSelector` nhận `unsupportedSizes`:
  - Disable nút không hỗ trợ, kèm tooltip.
  - Nếu đang chọn 512px thì tự chuyển về `1K`.
- Màn Create tính theo `getEffectiveModel()`. Màn Merge không gửi model lên server, nên tính theo `resolveGeminiRequestModel(undefined, getAdminGeminiModel(globalSettings))`.
- Server: `resolveGeminiImageSize` nâng 512px lên 1K, phòng trường hợp tab cũ vẫn gửi 512px.

> Trước bản này, chọn Pro + 512px luôn lỗi 400.

## 5. Chi phí (analytics)

`utils/geminiPricing.ts` (tách khỏi `hooks/useImageGeneration.ts`) tra giá theo từng model ID qua `canonicalGeminiModelId`. Model không nhận diện được dùng giá 2.1. Giá Standard tier, kiểm tra ngày 2026-10-08:

| Model | Input / 1M | Output ảnh / 1M | Thinking / 1M | Fallback theo ảnh (1K / 2K / 4K) |
| :--- | :--- | :--- | :--- | :--- |
| 2.1 | $1.50 | $30 | $7.50 | $0.0336 / $0.0504 / $0.113 |
| Nano Banana 2 | $0.50 | $60 | $3 | $0.0672 / $0.1008 / $0.1512 |
| Pro | $2 | $120 | không tính (chưa có giá) | $0.134 / $0.134 / $0.24 |

**Thinking tokens:** server trả thêm `thinkingTokens` (lấy từ `usageMetadata.thoughtsTokenCount`, tách riêng khỏi `candidatesTokenCount`). `estimateGeminiCost` tính phần này riêng. Trước đây thinking tokens không được tính vào chi phí.

1. `firebase deploy --only firestore:rules --project zvas-ai-image` (có **s**).
2. `gcloud run deploy ai-image-zvas --source . --region us-west1 ...` (Mode A). Nếu gcloud báo Python 3.9 thì đặt `CLOUDSDK_PYTHON`, xem `docs/06-live-deployment.md` § 2.
3. Smoke test:

   - Popup hiện Model ID Pro là `gemini-3-pro-image`.
   - Chọn 2.1 hoặc Pro thì nút 512px bị disable.
   - Tạo thử 1 ảnh.
